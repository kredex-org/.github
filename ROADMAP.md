# Roadmap

Kredex is **live on Stellar Testnet** today. This roadmap shows where we're heading and where you can help. It's a living document, so propose changes in [Discussions → Roadmap](https://github.com/orgs/kredex-org/discussions).

## ✅ Shipped (Testnet)

- On-chain borrower reputation and trust scoring
- Soulbound reputation NFT badges
- P2P loan marketplace with escrow
- Automated liquidity pools
- Default management and insurance events
- Oracle adapter for price feeds
- SEP-12 style KYC flow
- Wallet (Freighter) and passkey authentication
- Borrower, lender and admin dashboards, plus documentation site

## 🚧 Now: open-source foundations

- Contributor onboarding, templates and CI across all repos
- Better test coverage for contracts and product
- Documentation for every contract and API route
- Resolve community feedback (UX polish, transaction explorer links, clearer trust-score explanation)

## 🔜 Next

- Stronger KYC with fewer repeated questions
- Light/dark theme
- Mobile-first improvements and a native mobile app exploration
- Richer analytics and risk dashboards
- Security audit preparation and fuzz/property testing for contracts

## 🌅 Later: mainnet

- Fiat on/off ramps (e.g. MoneyGram Access)
- USDC and stablecoin support to reduce volatility
- Institutional, permissioned liquidity pools
- Independent security audit before any mainnet launch
- Governance and fee-parameter transparency

> Priorities shift based on community feedback and security needs. Want to take one on? Comment on the matching issue or start a discussion.
