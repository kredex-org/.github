# Getting Support

Not sure where to go? Use this table.

| I want to... | Go here |
| :-- | :-- |
| Learn how Kredex works | [Documentation](https://kredex-docs.vercel.app) |
| Try the app | [Live app (Stellar Testnet)](https://kredex.vercel.app) |
| Ask a question or get setup help | [Discussions → Q&A](https://github.com/orgs/kredex-org/discussions) |
| Share an idea | [Discussions → Ideas](https://github.com/orgs/kredex-org/discussions) |
| Report a bug | Open an issue in the relevant repo ([product](https://github.com/kredex-org/product/issues/new/choose), [contracts](https://github.com/kredex-org/contracts/issues/new/choose), [docs](https://github.com/kredex-org/docs/issues/new/choose)) |
| Report a security vulnerability | **Privately**, see [SECURITY.md](SECURITY.md) |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Follow news | [@kredexweb3 on X](https://x.com/kredexweb3) |

## Before opening an issue

1. Search existing issues and discussions. Your question may already be answered.
2. Check the [docs](https://kredex-docs.vercel.app).
3. Make sure your wallet (e.g. Freighter) is set to **Testnet** and funded through [Friendbot](https://friendbot.stellar.org).
4. Include versions, steps to reproduce, and screenshots or logs in your report.

> Kredex is on Testnet only. Please never share secret keys (`S...`) or seed phrases with anyone, including maintainers.
